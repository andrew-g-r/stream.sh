# Changelog

## 1.0.0

- Replace unsafe parsing, unquoted selection, undefined quit files, and Bash-4-only case conversion.
- Add recursive discovery, safe listing, local playlists, shuffle, seek/duration controls, loops, and configurable RTMP/RTMPS or local output.
- Add encoding profiles, explicit quality controls, scaling, compatible stream copy, muted playback, and loudness normalization.
- Add bounded retries, child-process cancellation, machine-readable progress, and diagnostics.
- Add local nginx/HLS examples, ShellCheck, macOS/Linux CI, and real FFmpeg smoke tests.
